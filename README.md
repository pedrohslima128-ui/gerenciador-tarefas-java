# 📝 Gerenciador de Tarefas em Java

> Uma aplicação de linha de comando desenvolvida em Java para gestão de tarefas diárias, aplicando conceitos de Orientação a Objetos e manipulação de estados.

---

## 📌 Sobre o Projeto

Este projeto foi construído para consolidar conhecimentos fundamentais em Java, permitindo adicionar, listar e atualizar o estado de tarefas em memória através de um menu interativo no terminal.

### 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 17 ou superior)
- **Conceitos Aplicados:**
  - Orientação a Objetos (Encapsulamento e Composição)
  - Coleções (`ArrayList`)
  - Estruturas de controlo e repetição (`switch`, `do-while`)

---

## 🎯 Funcionalidades

- [x] Adicionar novas tarefas à lista.
- [x] Listar tarefas com indicadores visuais de estado (Pendente / Concluída).
- [x] Marcar tarefas específicas como concluídas através do índice.
